# 📱 Guest Flow Manager — Projeto Android Nativo (Material Design 3)

Este diretório contém o projeto nativo completo e configurado para o **Android Studio mais recente (Ladybug, Koala, Iguana)** utilizando as diretrizes oficiais do **Material Design 3 (Material You)**.

---

## 🌟 Recursos Nativos Incluídos:
1. **Material Design 3 & Splash Screen Nativa:**
   * Utiliza o tema `Theme.Material3.DayNight.NoActionBar` com transição suave da Splash Screen do Android 12+.
2. **Acesso Nativo à Câmera do Smartphone:**
   * Abre a câmera traseira do celular e a galeria de fotos para envio de imagens nos módulos de **Achados & Perdidos** e **Vistorias**.
3. **Notificações Push Nativas & Vibração:**
   * Permissões de `POST_NOTIFICATIONS` e `VIBRATE` para receber alertas instantâneos de novos cafés, check-outs e pendências.
4. **Pull-to-Refresh:**
   * Puxe a tela para baixo para recarregar o painel a qualquer momento.
5. **Integração Externa:**
   * Disparo automático para o aplicativo do WhatsApp ao clicar em botões de contato.

## 🚀 Como Gerar o Arquivo `.apk` no Android Studio:

1. Abra o **Android Studio**.
2. Clique em **Open** (ou *File > Open*) e selecione a pasta:
   `c:\Users\mille\OneDrive\Hotel\Documentos hóspedes\Guest-Flow-Manager\android`
3. Aguarde o Gradle sincronizar automaticamente (10 a 20 segundos).
4. No menu superior do Android Studio, clique em:
   👉 **Build > Build Bundle(s) / APK(s) > Build APK(s)**
5. Quando o build finalizar, uma notificação aparecerá no canto inferior direito com o link **"locate"**.
6. O arquivo do seu APK estará pronto em:
   `android/app/build/outputs/apk/debug/app-debug.apk`
7. Basta enviar esse arquivo `.apk` para o seu celular Android via WhatsApp, Google Drive ou cabo USB e instalar!

## 📲 Opção Rápida de Instalação no Celular (Sem Android Studio):
Você também pode instalar o aplicativo no seu smartphone Android direto pelo Google Chrome:
1. No seu celular Android, abra o Google Chrome e acesse:
   👉 **https://corpflats.onrender.com**
2. Toque nos **3 pontinhos (Menu)** do Chrome no canto superior direito.
3. Toque em **"Instalar aplicativo"** (ou *"Adicionar à tela inicial"*).
4. O app será instalado no seu celular com ícone oficial, sem barras do navegador e com suporte completo a Push Notifications!
