# Hotel Trader

How to connect and map to Hotel Trader

You will need to have your direct contract with Hotel Trader for your property, please sign up with them and upload all your details and images etc.

Once the property is ready to connect please ask the support in the messaging inside the Extranet to connect to Channex.

## Create the Hotel Trader Channel

Go to the channels tab and click on "Create"

Select **HotelTrader** as the channel

<figure><img src="https://2514252617-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-LWLG7_BCMgWd3mn6DYg%2Fuploads%2FAG84lsZNttuQ3CVIyTkl%2FScreenshot%202026-09-30%20at%2022.25.04.png?alt=media&amp;token=a1930432-758e-48f8-b75f-d65734a9b1a8" alt=""><figcaption></figcaption></figure>

Title - Enter the name you would like here to describe this connection

Group: Choose the correct group of which property you need to connect.

Property: Choose the property you wish to connect from Channex

Hotel ID: This will be the Hotel Trader Hotel ID

Test Connection - This button will check if we have access to that property in Hotel Trader, if there is an error please check your property ID. You might need to ask Hotel Trader support to check if Channex is connected.

## Mapping

Click the mapping tab if the test button is a success, this will bring up mapping table.

Example:

<figure><img src="https://2514252617-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-LWLG7_BCMgWd3mn6DYg%2Fuploads%2F88LPj0S0ye4Q1GhmkxZa%2FScreenshot%202026-09-30%20at%2022.25.38.png?alt=media&amp;token=6944a55e-8751-420a-a600-1d588db02da5" alt=""><figcaption></figcaption></figure>

Now you can map the room types from Channex to the Hotel Trader Room types and also any rate plans.

Make sure all is mapped and nothing left unmapped.

Once you save the channel please activate it
